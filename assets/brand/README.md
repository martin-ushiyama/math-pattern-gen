# Math Pattern Gen / Brand assets

青 `#1644dd` とクリーム `#f3eedf`。模様とロゴを、同じドットでつなぐ配色です。

- `logo.svg`：本体と共通のドットロゴ。「Gen」を小さく配置。
- `ogp.png`：1200×630の共有用画像。OGPとX Cardで共用。
- `ogp.svg`：共有画像の編集用原本。
- `favicon.svg`：青い点の流れを切り取った模様。16pxでも点の形が残るように簡略化。
- `favicon.ico`：16・32・48pxを収録。
- `favicon-16.png` / `favicon-32.png` / `favicon-48.png`：各サイズのPNG。
- `apple-touch-icon.png`：180×180、ホーム画面追加用。

OGPの画像URLはGitHub Pagesの公開URLを絶対指定。faviconは相対パスなので、プロジェクト配下でもローカルでも参照できます。
