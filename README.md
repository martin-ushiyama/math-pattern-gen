## 何ができるか

11種類の構造からパターンを生成し、スライダーで形を追い込んで SVG / PNG に書き出す。OGP・note の見出し・帯バナー・スライドなど、よく使う寸法はプリセットで入っている。

**生成は全て決定的で、乱数を使っていない。** 同じパラメータからは常に同じ絵が出るので、気に入った状態はパラメータの組（レシピ）として控えておける。状態は URL のハッシュにも入る。

日本語と英語を切り替えられる（既定はブラウザの言語）。

初期配色は、青とクリーム色の「コバルト＆クリーム」。保存した設定URLを開いたときは、そのURLの配色を復元する。

## 収録している構造

| 構造 | 何をしているか |
| --- | --- |
| 極格子（ギヨシェ） | 同心円を一定ピッチで並べ、`cos(kθ + ar)` で濃淡をかける。紙幣や時計文字盤の彫刻と同じ構造 |
| ねじれたリボン | 3次元のリボンを正射影する。真横を向いた瞬間に格子が潰れて濃くなる |
| ひらっとした布 | 波打つ面を浅い俯角から見る。射影の潰れと法線陰影の2つで面に見せる |
| 等角写像 | `w = z²` / `w = z + 1/z`。角度を保つので歪んでも直交性が残る |
| 歪ませた等高線 | 低周波の波で座標を歪ませ、等値線の帯を置く |
| ねじれ格子 | 行ごとに回転角と伸縮を進める |
| モアレ | ピッチの近い2枚の格子を微小角ずらして重ねる |
| 準結晶 | N枚の平面波の和。周期が無いのに決定的 |
| ギブス現象 | 矩形波のフーリエ部分和。不連続の近くの振動は項数を増やしても消えない |
| 焦線（コースティクス） | 写像のヤコビアンの逆数を濃度に使う |
| 反応拡散 | Gray-Scott。決定的な偏微分方程式から有機的な模様が出る |

## 設計原則

背景として使えるパターンにするための3つ。ツール内にも表示している。

**濃淡を残す。** 点が隣と接触して面になった瞬間、ハーフトーンではなくただのベタ塗りになる。目安は最大粒径 ≦ 格子間隔 × 0.55。潰れたときに触るのは粒径ではなく分割数のことが多い。

**画面全体を覆う。** パターンが画面の一部に小さくまとまっていると「柄」に見えて弱い。四辺を貫いて外へ抜けること。

**中心・特異点は画面の外に置く。** 渦の芯や写像の特異点が画面内に見えると、「意味のわからない物体が中央に置いてある」という見え方になる。外に追い出すと、画面内には動きだけが残る。

## 使い方

1. 構造を選ぶ
2. スライダーで追い込む（「振ってみる」でランダムに探索もできる）
3. キャンバスの寸法と色を決める。他の絵に重ねるなら地を透明にする
4. **SVG** を保存、またはコピーしてデザインツールに直接ペースト。**PNG** なら倍率（×1〜×4）を選んで保存

SVG はベクターなので拡大しても粗くならない。数万個のドットでもパスは3本（濃淡3段）にまとまる。PNG は印刷や、SVG を受け付けない場所に貼るとき用。地を透明にしておけば PNG もアルファ付きで出る。

## 実装

ドット配列 `{x, y, r}` を作る純関数と、それを濃淡3段の `<path>` に変換する関数だけでできている。構造を足すには、パラメータの定義と `gen(p, W, H)` を書いて `ORDER` に名前を足す。

ロゴは 3×5 のドットマトリクスで字形を定義し、SVG で組んでいる。ツール自身が作る絵と同じ「点の集合」で名前を書いた形。
